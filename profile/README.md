# FormTango

**Form backend for any website.** Point a form at one URL; get submissions in an inbox, by email, and in the tools you use. No server code.

[formtango.com](https://formtango.com) · [Docs](https://formtango.com/docs) · [Guides](https://formtango.com/guides) · [Status](https://formtango.com/status)

## Start in one line

```html
<form action="https://formtango.com/f/YOUR_FORM_ID" method="POST">
```

Free for 100 submissions a month.
